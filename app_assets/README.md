# Discord Art Assets

Place your Discord application art assets here.

## roblox_logo.png

This image is used as the small icon in Discord Rich Presence.

- Recommended size: 512x512px
- Format: PNG
- Upload this to your Discord application at:
  [Developer Portal](https://discord.com/developers/applications) → Rich Presence → Art Assets
- Name the asset: `roblox_logo`
